Step 6 — Launch an AWS EC2 instance
Completed
You launched an EC2 instance named e-commerce-server in the Mumbai region (ap-south-1). It was running, with status checks passed.

For a new instance:
1. Sign in to the AWS Management Console.
2. Open EC2 → Instances → Launch instances.
3. Enter a name, such as e-commerce-server.
4. Select Amazon Linux 2023.
5. Choose an appropriate instance type, such as t3.micro, if suitable for your account and workload.
6. Create or select a key pair if needed for your chosen connection method.
7. Configure the security group with only the required inbound traffic.
8. Launch the instance.
9. Wait until its state is Running and status checks pass.
10. Use Connect → EC2 Instance Connect if available to open a browser-based terminal.
You also installed Git and updated the EC2 system packages.
